# Ngine - Angular Enterprise Framework

A complete framework for building enterprise Angular applications with a structured, opinionated approach.

## Features

- **Opinionated Structure** - Pre-configured Angular workspace with best practices
- **Docker-First** - Run anywhere with consistent environments
- **Enterprise Ready** - Includes testing, linting, and CI/CD setup
- **Nx Integration** - Monorepo support with powerful tooling
- **VSCode Integration** - DevContainer and extension support
