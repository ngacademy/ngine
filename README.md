# Ngine - Angular Project Scaffolding Tool

A Docker-based CLI tool for scaffolding enterprise-ready Angular applications with NX monorepo structure.

## What is Ngine?

Ngine is a scaffolding tool that helps you quickly create new Angular projects with:
- Pre-configured NX monorepo structure
- Angular Material and NgRx setup
- Firebase integration with emulators
- Storybook configuration
- Testing setup with Vitest and Cypress
- ESLint configuration
- DevContainer support for VS Code

## Features

- **Project Scaffolding** - Generate new Angular projects with a single command
- **Docker-Based** - Consistent environment without local dependencies
- **NX Monorepo** - Built on NX for scalable project structure
- **Pre-configured Libraries** - Common models, utilities, and Angular libraries
- **Firebase Ready** - Includes Firebase configuration and Firestore utilities
- **DevContainer Support** - Full VS Code integration with recommended extensions
